## Purpose

Every WordPress plugin admin page MUST follow a unified design system built on CSS custom properties, consistent typography, a shadow hierarchy, a shared animation library, and reusable component patterns.

This specification extracts all conventions from the reference implementation and defines the rules an AI needs to produce visually consistent, production-quality plugin UI.
