# Performance and Scale Proof Targets

> **Version:** 1.1.0  
> **Updated:** 2026-04-18

---

The project should eventually demonstrate:

| Target | Measure |
|--------|---------|
| Large datasets | Smooth interaction with 1000+ visible-capable items using virtualization |
| Drag-and-drop | Stable drag-and-drop with no visual jitter or dropped operations |
| Search | Responsive search results within 300ms for datasets of 5000+ items |
| Zoom navigation | Instant zoom transitions (<100ms perceived latency) |
| Board view | Independent column scrolling with 50+ cards per column without lag |
