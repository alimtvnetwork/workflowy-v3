# Accessibility Requirements

> **Version:** 1.1.0  
> **Updated:** 2026-04-18

---

| Requirement | Description |
|-------------|-------------|
| Labels | All interactive elements MUST have accessible labels (visible text or aria-label) |
| Keyboard navigation | Full keyboard support: Tab between sections, arrow keys within lists, Enter to activate, Escape to close |
| Focus indicators | Visible focus rings on all focusable elements |
| Tree semantics | Item list MUST use proper tree roles with expanded/collapsed states announced |
| Color contrast | MUST meet WCAG 2.1 AA standards (4.5:1 for normal text, 3:1 for large text) |
| Reduced motion | MUST respect user's reduced-motion preference by disabling animations |
| Drag-and-drop alternative | Keyboard shortcuts (⌘↑/⌘↓) provide the same reordering capability as drag |
| Tooltips | All icon-only buttons MUST have descriptive tooltips |
