## Purpose

`spec/12-consolidated-guidelines/` is a **redirect-index folder**: every file in it is a one-page stub that points at the SSOT spec for that domain. These criteria lock the redirect contract so the folder cannot drift from being "thin pointers" into being "second-copy normative text."

## Criteria

### Redirect-stub contract (structural)

| ID | Criterion | Source |
|----|-----------|--------|
| `AT-CONSOLIDATEDGUIDELINES-01` | Every file in this folder other than `00-overview.md`, `97-acceptance-criteria.md`, and `99-consistency-report.md` MUST be a **redirect stub** ≤60 lines pointing at exactly one canonical SSOT folder under `spec/`. | [`00-overview.md`](./00-overview.md) §Topics + AUD-C-01 |
| `AT-CONSOLIDATEDGUIDELINES-02` | A redirect stub MUST contain (a) Title with "— Redirect Stub", (b) a single canonical `→` link, (c) a 1-paragraph "Why this exists" note, (d) a Keywords block, (e) a Scoring table. No normative rule text. | All `NN-*.md` files in this folder |
| `AT-CONSOLIDATEDGUIDELINES-03` | A redirect stub MUST NOT define enums, code rules, or examples. If a rule appears in two places (here and the SSOT), the stub is a defect and the duplicate text MUST be removed in favour of a link. | All `NN-*.md` files |
| `AT-CONSOLIDATEDGUIDELINES-04` | The auto-generated TOC in `00-overview.md` (between `<!-- AUTO-TOC:START -->` and `<!-- AUTO-TOC:END -->`) MUST equal the on-disk file list and is regenerated by `scripts/spec-hygiene/11-generate-auto-toc.mjs`; manual edits inside the sentinels are forbidden. | [`00-overview.md`](./00-overview.md) §AUTO-TOC + `scripts/spec-hygiene/11-generate-auto-toc.mjs` |

### Coverage (every domain has a stub)

| ID | Criterion | Source |
|----|-----------|--------|
| `AT-CONSOLIDATEDGUIDELINES-05` | Every top-level numbered domain folder under `spec/` (excluding meta folders `18-spec-issues`, `19-glossary.md`, `20-enums-index.md`) MUST have a corresponding redirect stub here, OR be explicitly excluded in [`00-overview.md`](./00-overview.md) with a documented reason. | [`00-overview.md`](./00-overview.md) AUTO-TOC |
| `AT-CONSOLIDATEDGUIDELINES-06` | The 23 redirect stubs currently listed (`01-spec-authoring.md` … `23-generic-cli.md`) MUST each resolve to a real folder/file under `spec/` — broken redirect targets are caught by `scripts/spec-hygiene/03-check-links.mjs`. | [`00-overview.md`](./00-overview.md) §Topics |

### Relationship to canonical SSOTs

| ID | Criterion | Source |
|----|-----------|--------|
| `AT-CONSOLIDATEDGUIDELINES-07` | Each stub names its canonical SSOT exactly once and that SSOT is the **only** authority for the rule(s); the stub is "navigation only." | All `NN-*.md` files |
| `AT-CONSOLIDATEDGUIDELINES-08` | If a SSOT folder is renamed or moved, the redirect stub MUST be updated in the same change-set; orphaned redirects fail the link-check gate. | `scripts/spec-hygiene/03-check-links.mjs` |
| `AT-CONSOLIDATEDGUIDELINES-09` | The "App" stub (`13-app.md`) points at [`spec/31-app/`](../31-app/) and the "App Design System & UI" stub (`16-app-design-system-and-ui.md`) points at [`spec/32-ui-design/`](../32-ui-design/) — these two are load-bearing for the active product. | [`13-app.md`](./13-app.md), [`16-app-design-system-and-ui.md`](./16-app-design-system-and-ui.md) |
| `AT-CONSOLIDATEDGUIDELINES-10` | The "WP Plugin Conventions" stub (`20-wp-plugin-conventions.md`) points at [`spec/15-wp-plugin-how-to/`](../15-wp-plugin-how-to/), which is the chosen backend runtime per `mem://constraints/backend-runtime-deferred` (S003 closed). | [`20-wp-plugin-conventions.md`](./20-wp-plugin-conventions.md) + suggestions-tracker S003 |
| `AT-CONSOLIDATEDGUIDELINES-11` | The "Generic CLI" (`23-generic-cli.md`) and "Self-Update" (`17-self-update-app-update.md`) stubs MUST mark their SSOTs as **out-of-scope-for-current-stack** (Go-binary tooling, not WP plugin) without deleting the stub — they remain reference SSOTs for future stacks. | [`17-self-update-app-update.md`](./17-self-update-app-update.md), [`23-generic-cli.md`](./23-generic-cli.md) + `mem://constraints/backend-runtime-deferred` |

### Hygiene & versioning

| ID | Criterion | Source |
|----|-----------|--------|
| `AT-CONSOLIDATEDGUIDELINES-12` | This folder participates in the standard required-files gate: `00-overview.md`, `97-acceptance-criteria.md`, `99-consistency-report.md` MUST all exist. | `scripts/spec-hygiene/12-check-required-files.mjs` |
| `AT-CONSOLIDATEDGUIDELINES-13` | The folder's `99-consistency-report.md` MUST be regenerated whenever a stub is added/removed or its target SSOT changes; score MUST be ≥95/100 before merge. | `99-consistency-report.md` |

## Verification

```bash
# Stub line budget
for f in spec/12-consolidated-guidelines/*.md; do
  case "$(basename "$f")" in
    00-overview.md|97-acceptance-criteria.md|99-consistency-report.md) continue;;
  esac
  lines=$(wc -l < "$f")
  test "$lines" -gt 60 && echo "STUB OVER 60 LINES: $f ($lines)"
done

# Broken redirect targets
node scripts/spec-hygiene/03-check-links.mjs

# Full hygiene
node scripts/spec-hygiene/00-run-all.mjs
```
