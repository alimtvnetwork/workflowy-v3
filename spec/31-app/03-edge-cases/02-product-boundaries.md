### 16.1 What This Product Is
- An infinite outliner
- A structured thinking workspace
- A lightweight task and project management system
- A tree-based collaborative document system

### 16.2 What This Product Is Not
At this stage, it is not intended to become:
- A full Trello replacement
- A full Notion-style database suite
- A full CRDT-first collaborative editor from day one

The strongest version of this product is a low-latency (≤500 ms cold-open to first keystroke), minimal, deeply structured workflow tool that stays faithful to the tree model while adding curated advanced features (calendar, mirroring, board view) — and explicitly rejects feature parity with general-purpose note apps.
