# Keyboard Shortcuts — Complete Reference

> **Version:** 1.1.0  
> **Updated:** 2026-04-18

### 11.1 Global Shortcuts

| Shortcut | Action |
|----------|--------|
| ⌘Z | Undo |
| ⇧⌘Z | Redo |
| ⌘S | Save |
| ⌘P | Print |
| ⌘F | Open search |
| ⌘K | Open command palette |
| Escape | Close the topmost overlay or deselect the current item |

### 11.2 Item Editing Shortcuts

| Shortcut | Action |
|----------|--------|
| Enter | Split text at caret, create new sibling below with text after caret |
| ⇧↵ | Toggle the note editor for the current item |
| Tab | Indent (become child of the sibling above) |
| ⇧Tab | Outdent (move to parent's level, after parent) |
| ⌘↵ | Toggle complete / uncomplete |
| Backspace (on empty item) | Delete item, move focus to previous item |
| ↑ / ↓ | Navigate between visible items |
| ⌘↑ / ⌘↓ | Move item up/down in sibling order |

### 11.3 Text Formatting Shortcuts

| Shortcut | Action |
|----------|--------|
| ⌘B | Toggle bold |
| ⌘I | Toggle italic |
| ⌘U | Toggle underline |
| ⌘⇧X | Toggle strikethrough |

### 11.4 Item Type Conversion Shortcuts

| Shortcut | Converts To |
|----------|-------------|
| ⌥⌘1 | Heading 1 |
| ⌥⌘2 | Heading 2 |
| ⌥⌘3 | Heading 3 |
| ⌥⌘4 | Paragraph |
| ⌥⌘6 | Code Block |
| ⌥⌘7 | Quote |
| ⌥⌘8 | Bullets |
| ⌥⌘9 | To-do |

### 11.5 Item Action Shortcuts

| Shortcut | Action |
|----------|--------|
| ⇧⌘M | Open Mirror To… picker |
| ⇧⌘D | Duplicate item + children |
| ⇧⌘L | Copy internal link to clipboard |
| ^M | Add comment |
| !! (typed in content) | Opens date picker |

### 11.6 Markdown Auto-Conversion (typed shortcuts)

| Typed Sequence | Converts To | When |
|---------------|-------------|------|
| # + Space | Heading 1 | At the start of an empty item |
| ## + Space | Heading 2 | At the start of an empty item |
| ### + Space | Heading 3 | At the start of an empty item |
| - + Space | Bullet | At the start of an empty item |
| [] + Space | To-do | At the start of an empty item |
| 1. + Space | Numbered | At the start of an empty item |
| > + Space | Quote | At the start of an empty item |
| ``` + Space | Code Block | At the start of an empty item |
| --- + Enter | Divider | When this is the entire content of the item |
