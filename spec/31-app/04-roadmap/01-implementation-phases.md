# Implementation Phases

> **Version:** 1.1.0  
> **Updated:** 2026-04-18

---

### Phase 1 — Core Outliner ⭐ (Start Here)
- [ ] Authentication (signup, login, logout) with email/password
- [ ] Recursive bullet list with infinite nesting
- [ ] Basic CRUD (create, edit, delete items via keyboard)
- [ ] Indent / outdent with Tab / Shift+Tab
- [ ] Zoom in/out with breadcrumb navigation
- [ ] Expand / collapse items with child count badge
- [ ] Debounced autosave with status indicator
- [ ] Optimistic UI updates (instant feel, revert on error)
- [ ] Basic navbar: home, back/forward, breadcrumbs

### Phase 2 — Rich Editing
- [ ] Text formatting toolbar (bold, italic, underline, strikethrough, code)
- [ ] Headings (H1, H2, H3) and paragraph rendering
- [ ] "Turn into…" type conversion with all types
- [ ] To-do checkboxes with complete action (⌘↵)
- [ ] Notes on items (add, edit, display)
- [ ] Numbered lists, quotes, code blocks, dividers
- [ ] Markdown auto-conversion shortcuts
- [ ] Text color picker (A ▾)

### Phase 3 — Navigation & Menus
- [ ] Full navbar with all elements specified in §2
- [ ] Settings menu (⋮) with all actions and groups
- [ ] Item context menu with all actions specified in §5
- [ ] Search functionality with full-screen overlay
- [ ] Today shortcut and date features
- [ ] Favorites / bookmarks (sidebar + star toggle)
- [ ] Sidebar with favorites, recent items, tags
- [ ] Keyboard shortcuts reference panel
- [ ] Command palette (⌘K)

### Phase 4 — Collaboration & Advanced
- [ ] Mirror To… (full mirror system per §8)
- [ ] Board view (Kanban per §6)
- [ ] Share items with permission levels (§7)
- [ ] Comments and mentions (@)
- [ ] Move to… (today, tomorrow, next week, custom location)
- [ ] File upload and attachments
- [ ] Templates (save and apply)
- [ ] Duplicate (deep clone)
- [ ] Sort (A-Z, Z-A)
- [ ] Export (OPML, plain text, JSON, Markdown)
- [ ] Trash and restore (§10)
- [ ] Multi-select and bulk actions (§12)

### Phase 5 — Polish & Scale
- [ ] Undo/redo history (full action stack)
- [ ] Print support
- [ ] Usage limits and upgrade flow (free tier: 250 items)
- [ ] Settings panel (theme, font size, default view, show completed, auto-collapse depth)
- [ ] Help and bug report
- [ ] Dark mode support (full theme switching)
- [ ] Mobile responsive layout (sidebar overlay, touch-friendly drag)
- [ ] PWA support (installable, offline-first)
- [ ] Performance: virtualized list for 1000+ items
- [ ] Onboarding flow for new users
- [ ] Accessibility (screen reader support, keyboard navigation, ARIA attributes, proper color contrast)
