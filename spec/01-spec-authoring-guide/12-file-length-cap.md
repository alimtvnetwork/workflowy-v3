# File Length Cap

> **Updated:** 2026-04-19
> **Enforced by:** `scripts/spec-hygiene/05-check-file-length.mjs` (run via `00-run-all.mjs`)

## Rule

Every `.md` file under `spec/` MUST stay within the following thresholds:

| Threshold | Lines | Behavior | Action |
|-----------|-------|----------|--------|
| Soft (warn) | **>400** | ⚠️ Warning printed to stdout | Plan a split into a same-name subfolder |
| Hard (fail) | **>600** | ❌ CI fails (exit 1) | MUST split before merge |

> **2026-04-20 update (L-5):** the hard-cap was tightened from 800 → 600 lines after the H-1 tier split every monolith ≥505 lines. Override only in emergencies via `SPEC_LENGTH_FAIL_AT=800 node scripts/spec-hygiene/05-check-file-length.mjs`.

A 400-line ceiling keeps any single file readable in one screen and small enough for an AI to load entirely into context without truncation. The 600-line hard cap is the absolute upper bound — beyond that, AI handoff reliability degrades sharply (verified by the AUD-L-01 audit).

## Exclusions

The checker ignores files where length is expected and acceptable:

- `spec/spec-index.md` — auto-generated by `04-generate-index.mjs`
- `**/99-consistency-report.md` — aggregated audit reports
- `**/98-changelog.md` — append-only history

## How to Split

When a file approaches 400 lines:

1. **Create a same-name subfolder** in place of the monolith:
   ```
   spec/15-wp-plugin-how-to/04-logging-and-error-handling.md   (deleted)
   spec/15-wp-plugin-how-to/04-logging-and-error-handling/     (new folder)
   ├── 00-overview.md          ← table of contents + parent linkbacks
   ├── 01-two-tier-logging.md
   ├── 02-debug-mode.md
   └── ... (one topic per file, all <400 lines)
   ```
2. **`00-overview.md`** lists every topic file with a one-line description and links to siblings.
3. **Update inbound references** — every link to the old `foo.md` becomes `foo/00-overview.md`.
4. **Run** `node scripts/spec-hygiene/00-run-all.mjs` until all checks pass.
5. **Update the tracker** in `.lovable/plan.md`.

## Why a `00-overview.md` and not a flat folder

The overview file replaces the monolith as the canonical entry point — inbound links resolve cleanly, and a fresh AI session reading the folder gets a guided tour instead of an alphabetical file dump.
