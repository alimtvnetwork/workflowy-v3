## Overview

This specification defines the Role-Based Access Control (RBAC) pattern using [Casbin](https://casbin.org/) for Go-based CLI tools. Casbin provides a flexible, policy-based authorization framework that integrates seamlessly with SQLite via the GORM adapter.
