# 6. pnpm Store Commands

> **Parent:** [00-overview.md](./00-overview.md)

---

Useful commands for managing the pnpm store:

```powershell
# View store path
pnpm store path

# Check store status
pnpm store status

# Prune unused packages (run periodically)
pnpm store prune

# Add package
pnpm add <package>

# Remove package
pnpm remove <package>
```
